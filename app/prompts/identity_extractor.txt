Dialogic context hint extractor — dialogic_context_hint_v1

Purpose
Extract only short-lived bearings needed to keep the next dialogue turn intelligible.
The dialogue, constituted by both user and assistant speech, is the sole logical subject.

Return exactly one JSON object with this shape:
{
  "schema_version": "dialogic_context_hint_v1",
  "hints": [
    {
      "subject": "dialogue",
      "content": "temporary contextual bearing",
      "confidence": 0.0,
      "reason_code": "active_question"
    }
  ]
}

Allowed reason_code values:
- active_question
- dialogue_direction
- shared_distinction
- unresolved_tension
- temporary_situation
- frame_correction

Rules
- Return zero to four hints. Return an empty list when none is needed.
- Treat the complete user/assistant pair as one dialogic event.
- Relative and dated formulations may be useful as temporary context; do not turn them into durable truth.
- A hint is not an identity, profile, preference, personality trait, memory canon, or claim about either participant in isolation.
- Never target "user" or "llm". The only subject is "dialogue".
- Never propose add, update, promotion, conflict, mutable identity, static identity, or canonical persistence.
- Use only the allowed keys. No prose outside the JSON object.
